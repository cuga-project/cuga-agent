B Set up a debugger & trace the flow

The point: watch a request travel the whole path so you understand every piece. Uses VS Code + the committed launcher.

#Do thisExpected☐Notes
1Start the registry (Run & Debug → "API Registry Demo"), or leave events_up.sh's registry running.registry :8001 up
2Launch the debug server: Run & Debug → "Events: CUGA server :8100 (debug)" (runs scripts/run_events_server.py, justMyCode:false).console prints [events] EVENTS_ENABLED=1 …; :8100 up
3Set breakpoints (the request path, in order):
  • events/app.py → invoke() (the seam; token check, scope, agent)
  • events/concierge.py → find_or_create_flow() (NL→flow args)
  • events/ap_engine.py → create_schedule_flow() (AP ops + send step)
  • events/runtime.py → CugaRuntime.run() (the worker)
4 red dots set
4Trigger it — in another terminal, arm a poll via the concierge:
GT=$(grep '^GATEWAY_TOKEN=' .env|cut -d= -f2-|sed 's/ *#.*//'|tr -d ' ') curl -s -X POST "http://localhost:8100/api/concierge" \ -H 'content-type: application/json' -H 'x-user-id: admin' \ -d '{"text":"every 5 minutes send me the bitcoin price","thread_id":"gw:telegram:12345"}'
breakpoints hit in order; step through & inspect agent, kind, sink, the AP ops
5Watch a NOW seam — set a breakpoint only in invoke(), then call it directly:
curl -s -X POST http://localhost:8100/invoke \ -H 'content-type: application/json' -H "X-Gateway-Token: $GT" \ -d '{"text":"price of bitcoin?","agent":"pricebot","source":{"type":"channel","name":"web","thread_id":"web:1"},"event":{"kind":"message","payload":{}},"scope":"default/default/admin","deliver":false}'
token check passes → runtime.run(pricebot…) → a number returns
Tip: justMyCode:false lets you step into CUGA graph + langchain internals. Turn it back on to stay in the events layer. Logs stream to the Debug Console; add LOGURU_LEVEL=DEBUG in the launch env for more.

✓ Definition of done — Phases 1 & 2

You're good on P1 & P2 when all of the below hold:

  • Phase 1: server up behind EVENTS_ENABLED; /invoke auths & runs a pre-built CUGA agent with real MCP tools; store persists; offline suite green (~60).
  • Phase 2: AP up + worker healthy; concierge does answer-now / create / dedup / decline; classifier hits NOW·CRON·POLL·PUSH; a Telegram round-trip works (inbound reply and a scheduled delivery); credentials land in AP; identity/permissions resolve; Studio shows real state; live e2e 6/6.
Not in P1/P2 (don't block on these): Discord/Slack live round-trips, PUSH live (GitHub/Box/Gmail), OAuth connect live, multi-user isolation live, and the NL→flow benchmark — those are Run/MVP items on the Board.
