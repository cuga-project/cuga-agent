CUGA Events — What you can unlock

Every example is one sentence in one grammar: TRIGGER + SOURCE (a channel message · the clock · an integration event) + SKILL (an agent) + SINK (a channel · email · webhook). This page maps the whole space against what's live now, what's one connect away, and what needs a new agent. Example domains are drawn from the cuga-apps catalog.

6 The genuinely-new combinations (direct backends)

Cells that were closed before this week's direct-Slack + direct-Box + direct-channel-delivery work:

  • Integration IN → chat OUT, no AP — a Box file → Slack (not just email).
  • Clock → Slack — any CRON/POLL can now deliver to Slack (previously AP-only send-step, and Slack had no AP connection).
  • Slack as a full conversational channel — inbound and scheduled-delivery target, live-verified.
  • Cross-channel — ask from Discord, get answered in-thread; watch on a timer, deliver to a different channel than you asked from.

7 Honest gaps what "🔨" really means

#GapCloses when…
1PUSH-from-chat is not wired to direct Box. The concierge's find_or_create_flow(kind=push) routes to AP (create_push_flow) → asks you to connect Box (OAuth). The direct poll that works isn't reachable from an utterance, and nothing schedules it automatically.a box:direct branch in the concierge + a CUGA-side poll scheduler
2Box watcher passes the file name, not its content — the agent can't read the bytes yet (cuga_text_extract_text → File not found).a Box download in box_direct (or a Box-read MCP tool)
3The "🔨 build an agent" examples have the skill (an MCP server or a cuga-app), but no seeded agent advertising it — so the router declines them.a builder registers the agent (skill + channels + integrations)
4Gmail / GitHub / webhook integrations aren't connected in AP.connect Gmail/GitHub (Studio → Integrations) or wire the generic webhook

So an example is ✅ live only when all three hold: a seeded agent advertises the skill, its source + sink are wired, and its integration (if any) is connected. Most cells are one small step from green.
