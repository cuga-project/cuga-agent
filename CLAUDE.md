# Claude Code — Project Instructions

## Git commits

- Always append `[skip ci]` to every commit message title line.
- Do **not** include a `Co-Authored-By` trailer in commit messages.
- Follow [Conventional Commits](https://www.conventionalcommits.org) with scope and bullet-point descriptions.

## Running the app

- If `cuga start` is not recognised, remind the user to activate the virtual environment first: `source .venv/bin/activate`
