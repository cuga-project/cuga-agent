Event-Driven CUGA — API Spec

34 endpoints. Every one has example payloads, real responses (including the interesting failures), and the callers that use it in practice. Set a base URL above and hit Try it on any endpoint to run it against your own stack.

This page is open from file://. The browser sends Origin: null; the server echoes Access-Control-Allow-Origin: null, which some browsers honour and others refuse — so Try it may fail here with an opaque Failed to fetch. For a reliable round trip serve the page over HTTP: make api-spec. Copy as curl works either way.
The shape of the system. /invoke is the one seam everything converges on: every armed Activepieces flow, every chat channel, the Box poller and the generic webhook all normalise their event into an envelope and POST it here. /api/concierge is the natural-language front door that turns a sentence into a standing flow. Everything under /api/events/ exists so the Studio can stay dumb — it renders what the backend reports rather than deciding anything itself.

Which endpoints actually matter to you

Not every endpoint is load-bearing. Two do the reasoning; four receive events from the outside world; twenty-five exist so the Studio can render a page. Use the tier buttons in the bar above to see one group at a time.

Isolation

Every endpoint resolves a principal (tenant/instance/user) from X-Tenant-Id / X-Instance-Id / X-User-Id headers, falling back to default/default/local. You only ever see your own subscriptions, runs and connections. Another principal's id returns 404, never 403 — a 403 would confirm the id exists.

Failure, not silence

A missing optional dependency is a 501 naming it, not a 500. An unreachable Activepieces degrades reads to unknown/empty rather than erroring. Anything that could silently do nothing — a stale Box token, a dangling flow — is made loud instead.

Auth, honestly

Three seams are protected only when their secret is set: GATEWAY_TOKEN for /invoke and the Box poll, SLACK_SIGNING_SECRET for the Slack receiver, and EVENTS_WEBHOOK_KEY for the generic hook. Unset, each accepts anything that reaches it. That is fine on localhost and dangerous behind a public tunnel.

This is what make test-suite-now sends. source.type:"time" + event.kind:"runonce" means "just answer, don't arm anything". The response's meta.mcp proves the agent reached a real tool instead of answering from the model's memory.
