Events integrations — prerequisites

Set each integration up manually with the steps below, drop its keys in your .env, then run its check script to confirm the keys actually work. This stage is deliberately independent of CUGA and Activepieces — it only talks to each vendor's API, so a green check means the credential is good before any of the runtime is involved.

Verify everything at once: python3 events_docs/setup/scripts/check_all.py — unconfigured connectors are skipped, not failed.
